# Notifications

AgentHub can notify you when a task is completed.

## In-App Notification

By default, completion signals appear in the AgentHub UI.

## Browser Push Notification

If Web Push is configured and enabled:

1. Grant browser notification permission
2. Keep the AgentHub site subscribed to push
3. Receive completion reminders even when the page is not focused

## Recommended Setup

- Enable notifications for long-running tasks
- Keep noisy tasks grouped by clear naming conventions
- Use history + notifications together for efficient follow-up
