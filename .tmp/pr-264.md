## Summary

- add a narrow `@chenglou/pretext` POC for ACP conversation virtualization
- estimate height only for text-dominant ACP rows (`agent_message` / `user_message`)
- keep tool/thinking/plan rows on the existing coarse fallback path

## Why

The current ACP conversation virtualization uses one global average row height. That keeps the code simple, but long text-heavy histories can accumulate spacer error and make scroll anchoring drift more than necessary. `pretext` is a good fit for this narrow case because it can estimate multiline text layout without forcing DOM measurement.

This PR keeps the scope intentionally small:

- ACP conversation only
- message bubbles only
- no input/textarea/layout shell changes
- no attempt to replace DOM truth after render

## Implementation

- add `web/src/hooks/conversation_height_estimate.ts`
  - wraps `@chenglou/pretext` behind a safe message-height estimator
  - caches prepared text + estimated heights
  - builds prefix-sum height models for binary-search virtualization
- update `web/src/hooks/use_acp_conversation.ts`
  - track viewport width alongside scroll top/height
  - rebuild the text-aware height model only when source items, width, or fallback average changes
  - keep slice selection cheap during scroll
- add focused unit coverage for the new estimator and variable-height slicing
- document the contract and add a follow-up verification TODO
