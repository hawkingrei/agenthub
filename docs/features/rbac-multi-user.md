# Historical RBAC Multi-User Proposal

This document is historical and is not a normative contract.

It described a superseded global role hierarchy (`maintainer`, `member`, `visitor`) and broad
cross-Team resource visibility. Those rules do not match the implemented local account capability
model or the planned Teamspace collaboration boundary.

Use these active specifications instead:

- [Access Control And Roles](access-control-and-roles.md) for local account roles, platform
  capabilities, and server-side authorization.
- [Teamspace Multi-User Collaboration](teamspace-multi-user.md) for invite-only Teamspace
  membership, visibility, review, Task/Step single ownership, and read-only forks.
- [Team Goal And Fork Control](team-goal-fork-control.md) for task-backed goal leases and capacity
  control.

No implementation should use this document as a source of role names, permission matrices, schema,
or API contracts.
