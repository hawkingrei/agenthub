# 输出缓存一致性更新

## 背景

`loadAgentEvents` 在合并缓存时依赖 `setState` updater 的副作用结果，遇到并发渲染或 SSE 同步追加时可能出现输出回退或缓存覆盖。

## 范围

- 为输出缓存与 ACP 缓存引入同步快照引用。
- 统一通过缓存更新函数写入缓存，避免在 updater 中依赖副作用。
- `loadAgentEvents` 只负责更新缓存与元信息，输出列表由缓存驱动的 effect 统一更新。

## 关键决策

- 使用 ref 维护最新缓存快照，所有写入路径都更新同一份快照。
- 保留实时输出的追加逻辑，避免改变用户感知延迟。

## 验证

- 手动：SSE 输出与轮询同时触发时，输出顺序稳定且不回退。
- 自动化：

```bash
cd web
npm test
```
