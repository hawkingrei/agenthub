# SSE 断线重连与兜底轮询

## 背景

SSE 在网络抖动或代理断链时可能进入错误状态。需要主动关闭失效连接并持续重试，避免前端停止接收输出。

## 范围

- `source.onerror` 中主动关闭当前 SSE 连接。
- 引入指数退避的重连调度。
- 保持轮询兜底持续运行，保证断线期间仍能拉取输出。

## 关键决策

- 采用 1s 起步、上限 30s 的指数退避，`onopen` 时重置重连计数。
- 关闭连接后清理 `sseRef`，避免误判连接已打开。
- 重连与轮询互不依赖，任一可用即可持续更新。

## 验证

- 手动：断网 10-20 秒后恢复，确认输出继续更新且 SSE 恢复连接。
- 自动化：

```bash
cd web
npm test
```

## 后续

- 观察长时间断网后恢复时的重连稳定性，必要时调整退避上限。
